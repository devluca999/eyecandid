Pill buttons for every action — primary ink for the one main action, secondary glass when floating over footage, quiet text for everything else.

```jsx
<Button>export</Button>
<Button variant="secondary" icon="refresh-cw">try again</Button>
<Button variant="quiet">skip</Button>
<Button variant="secondary" icon="mic" title="talk" />
```

- Sizes: md 44px, lg 52px (marketing CTAs). Never below 44px.
- Never use accent as a button fill — accent is selection only.
