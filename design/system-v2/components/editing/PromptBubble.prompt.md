Select-and-talk bubble — appears beside a selected Lens or bead so the user can type or say what should change.

```jsx
<PromptBubble context="selected · 0:04–0:09" suggestions={['tighter','cut the ums','add b-roll']} reply="tightened the intro · removed 2 pauses" />
```

- `listening` swaps the input for a live voice meter. `tail` points at the selection. Only appears on selection — never permanently on screen.
