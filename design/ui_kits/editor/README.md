# Editor UI kit

`index.html` + `editor.js`: one canvas, three modes (theater / edit / board), every feature reachable in place. **⌘K** lists everything.

- **Theater** (Night): circle Lens, karaoke captions, thin progress ring, play pill. Click the Lens → it spring-morphs into the editing rect.
- **Select and talk**: hold **Space** (or drag) to brush; glowing outline; release → glass bubble with live waveform + transcript. Run → shimmer inside the selection → result reveals inside the selection → before/after slider → keep / try again (adds a take).
- **Right-click the Lens**: aspect ratio (circle, 9:16, 4:5, 1:1, 16:9, 1.85, 2.39 — Lens morphs), style (my styles first), edit with ai, takes (flick / mix), save as style, export (cutdowns).
- **Bead thread**: S split at playhead, drag bead edges to trim, click hook / reveal / best line ticks to zoom + loop, "moments only", struck fillers click to restore, '+' between beads → voice (records live onto a voice thread), b-roll, grade (swatches + drop a reference), music, text.
- **Takes**: fanned stack right of the Lens; flick the top card (3D tilt). **Mix takes** from the menu.
- **Captions**: click a word on the footage to retype, drag the block to move, click it for looks (word pop, karaoke, lower third, punch) and translate.
- **Dials** (left of the Lens): pace, b-roll density, energy — re-edit live.
- **Timeline**: hover the bottom edge or ⌥T. Weave on the b-roll track: faint raw ribbon, lit windows with reasons on hover, click to pin, "on face" brackets, density dial. Cut-aways also play in the Lens.
- **Export**: hover the Lens → ratio / cutdowns / download → ring traces the Lens edge → "copied link · download".
- **Drop a file** anywhere (or ⌘K → drop a clip): analysing shimmer, then beads spring out.
- **Sets + word effects**: crumb → Everstock / ten-minute setup. Switch set to the generated white void; drag across "ten minutes" → attach "a giant timer drops and rings"; play.
- **Idea engine**: crumb → new ad. "What's the idea?" → hook critique, three angles, ghost beat sheet, risks; or a template row → new storyboard row.
- **Board**: tldraw-style canvas — handwritten beat labels, sticky, arrows, drag cards, tools (sticky, arrow), zoom, "play row as cut".

Theme switches automatically (Night in theater, Paper elsewhere); the top-right button overrides it.
