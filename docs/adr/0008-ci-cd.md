# 0008 · CI/CD on GitHub Actions

**Status:** accepted · 2026-11-15

**Decision.** Required checks on every PR: lint, typecheck, Vitest (core, ui, convex via `convex-test`), Playwright web e2e against a local Next build with a local Convex backend, engine pytest with the CPU stub plus the contract test, visual regression (Playwright screenshots of key screens). Preview jobs, which need secrets and are skipped with a notice until they exist: Vercel preview, Convex preview deployment, EAS preview build with Maestro. On `main`: deploy Convex and Vercel to production, publish an EAS Update. On `main` and tags: build the CUDA worker image to GHCR; on tags, publish the `eyelore-engine` Python package as a release asset for the Colab bootstrap.

**Consequences.** Forks and keyless runs stay green on the checks that don't need secrets; deploy jobs report "skipped · needs keys" rather than silently passing.

**Amendment (2026-11-16): mobile e2e builds on the runner.** On the free EAS tier no cloud build ever left the queue: `eas build --wait` sat `IN_QUEUE` until the job timed out, and cancelled runs left their builds queued ahead of the next. The mobile check now runs `expo prebuild` and `gradlew assembleRelease` (x86_64, debug-signed) on the GitHub runner and drives it with Maestro on an emulator against a local Convex backend and a real CPU worker over `adb reverse`, with `EYELORE_E2E=1` allowing cleartext to localhost in that build only. It needs no secrets and runs when `apps/mobile`, `packages`, `convex`, `services` or the workflow change. Runner-up: keep the cloud build with a longer timeout (the queue wait is unbounded). Installable EAS builds are made by hand until a paid build tier or a self-hosted runner exists.
